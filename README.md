# alltimeall.com Smart Android Application

অ্যান্ড্রয়েড অ্যাপটি **alltimeall.com** ওয়েবসাইটের জন্য সম্পূর্ণ রেডি করা হয়েছে।

## 🚀 বৈশিষ্ট্যসমূহ (Features)

1. **ব্র্যান্ড প্রাইমারি কালার ও থিম**: alltimeall.com ওয়েবসাইটের অরিজিনাল অরেঞ্জ প্রাইমারি থিম (`#F97316`) ও ম্যাটেরিয়াল ডিজাইন ৩ ইউআই।
2. **কাস্টম প্রোগ্রেস বার**: ওয়েব পেজ লোড হওয়ার প্রোগ্রেস রিয়েল-টাইমে প্রদর্শন করবে।
3. **Pull-to-Refresh**: স্ক্রিনের উপর থেকে নিচে টেনে দ্রুত পেজ রিফ্রেশ করার সুবিধা।
4. **অফলাইন অ্যান্ড নেটওয়ার্ক ডিটেকশন**: ইন্টারনেট সংযোগ বিচ্ছিন্ন হলে বা না থাকলে সুন্দর অফলাইন পেজ প্রদর্শন করবে এবং **"পুনরায় চেষ্টা করুন"** বাটনে ক্লিক করে আবার যুক্ত হতে পারবে।
5. **ক্যামেরা ও ফাইল আপলোড সাপোর্ট**: প্রফেশনাল ইমেজ ও ফাইল আপলোড ইন্টেন্ট নির্বাচন করার সুবিধা।
6. **ইনভয়েস ও ফাইল ডাউনলোড ম্যানেজার**: বিডি ক্যাশ মেমো, ইনভয়েস ডাউনলোড সরাসরি ফোন ডাউনলোডে সেভ হবে।
7. **এক্সটার্নাল লিঙ্ক হ্যান্ডলিং**:
   - হোয়াটসঅ্যাপ চ্যাট (`whatsapp://`, `wa.me`)
   - ফোন কল (`tel:`)
   - ইমেইল (`mailto:`)
   - পেমেন্ট গেটওয়ে (bKash, Nagad, SSLCommerz, Rocket)
8. **স্মার্ট ব্যাক বাটন**: ব্যাক বাটন প্রেস করলে আগের পেজে ফিরবে এবং মূল পেজে ডাবল প্রেস করলে অ্যাপ বন্ধ করার অ্যালার্ট দিবে।

## 🛠️ কিভাবে APK বিল্ড করবেন (How to Build APK)

1. **Android Studio** সফটওয়্যারটি চালু করুন।
2. `Open` এ ক্লিক করে `d:\alltimeall apps` ফোল্ডারটি নির্বাচন করুন।
3. গ্রেডেল সিঙ্ক (Gradle Sync) শেষ হওয়া পর্যন্ত অপেক্ষা করুন।
4. মেনু থেকে **Build > Build Bundle(s) / APK(s) > Build APK(s)** এ ক্লিক করুন।
5. বিল্ড শেষে তৈরি হওয়া APK ফাইলটি যেকোনো অ্যান্ডয়েড ডিভাইসে ইন্সটল করে ব্যবহার করা যাবে!

## 📦 প্রজেক্ট স্ট্রাকচার (Project Structure)

- `app/src/main/java/com/alltimeall/app/MainActivity.kt`: প্রধান ওয়েব ভিউ, ব্যাক প্রেস, শেয়ার, ফাইল আপলোড ও ডিপ লিঙ্ক কোড।
- `app/src/main/java/com/alltimeall/app/NetworkUtils.kt`: রিয়েল-টাইম ইন্টারনেট চেকার।
- `app/src/main/res/layout/activity_main.xml`: ওয়েব ভিউ, প্রোগ্রেসবার ও অফলাইন স্ক্রিনের লেআউট।
- `app/src/main/res/values/colors.xml`: ব্র্যাণ্ড কালার কোডসমূহ।
- `app/src/main/res/values/strings.xml`: বাংলা এবং ইংরেজি ডায়ালগ টেক্সট।
- `app/src/main/AndroidManifest.xml`: পারমিশন ও ফাইল প্রোভাইডার কনফিগারেশন।
